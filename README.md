# Tracy Maliaka | Data Analyst Portfolio

React portfolio (Vite + React Router) in gold and white / gold and black.

```
npm install
npm run dev      # live preview
npm run build    # production files in dist/
```

Edit all text in `src/data/content.js`. For a real hero photo, put it in `public/` and set `heroPhoto: "/tracy.jpg"`.
Deploy on Vercel (included `vercel.json`) or Netlify (send all paths to `index.html`).
